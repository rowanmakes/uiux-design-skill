## 范围、口径与结论

按简报评估中文 HTML 原型：左侧项目、中间结果网格、右侧参数检查器、队列与进度，以及 Windows/macOS 菜单、快捷键和右键菜单设计。图片必须是标注占位的图形，项目、参数和队列以固定样例素材为准。桌面客户端任务优先考虑可见的工作流与状态一致性，不以功能多、代码长或效果炫加分。

【截图观察】来自实际打开的 PNG；【代码推断】来自对应 HTML；本次没有运行或操作页面。下文 HTML 行号指 `blind/07/<标签>/output/index.html`，截图名指对应标签 `shots/`。评分锚点：1 明显不可用/缺失，3 基本成立但粗糙，5 充分且有证据；2、4 为中间档。

加权分子 = 任务清晰度 + 0.5×品牌辨识度 + 构图与节奏 + 内容真实性 + 1.5×状态与交互 + 响应式 + 可访问性基础；权重和为 7，分子满分 35，加权均分 = 分子÷7，保留两位小数。缺失项不计零分，不进入排序。
