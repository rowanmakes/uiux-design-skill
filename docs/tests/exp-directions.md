# 实验 E1：先探索方向再深化 · 2026-10-21

- 结果分支：`test/exp-directions`
- 生成：Antigravity（gemini-4-argon-high），两组都不加任何 Skill，条件相同：能看参考网站截图、能截图自查、可用 Google Fonts、样例声明只在页脚一次、60 分钟上限
- A2 组：直接做一版，截图后改一轮（2 次运行）
- D 组：先做 3 个骨架不同的首屏方向，截图对照参考自评，选一个深化（2 次运行）

## 对应关系

P = D-2，Q = A2-2，R = D-1，S = A2-1。（整理阶段 mapping 曾在 worker 终端回显一次，见 `runs/e1-summary.md`。）

## 结果

1. **流程决定了是否跳出默认外观，2/2 对 2/2。** A2 的两次（Q、S）几乎一模一样，而且和第一轮三组是同一个样子：暖纸色底、衬线标题、左文右卡。参考截图、好字体、能看画面，都没让它们离开这个默认。D 的两次（P、R）都离开了：深色底，把风味曲线做成主视觉（数据即图像），明显更精致。
2. **D 组自己挑方向的眼光是短板。** 两次都做出了一个"居中单一物件：豆袋"的方向（D-1 的 d2、D-2 的 d2）：大面积留白、产品居中、一句话标题，最接近用户"留白、干净、简约、大气"和苹果式的品味。但两次都没选它，都选了信息最多、最像科技产品的"深色风味控制台"。
3. **新的趋同：** P 和 R 彼此很像（深色、风味曲线、控制台布局），很可能是被 Linear、Grok 这类深色参考带过去的。参考网站全是科技产品，会把非科技题材也拉向科技外观。
4. 是否适合咖啡烘焙这个题材（产品契合度），需要用户判断。

## 对 Skill 的含义

- 三方向探索应该是 Skill 的核心步骤，而且骨架约束要具体（证据：A2 与 D 的差异）。
- 方向选择默认交给用户：摆出几个首屏就停。无人值守时才自己选，并且明确警告"不要因为更复杂、信息更多而选"，以用户的品味画像为准。
- 参考板要按题材挑，不能只用用户喜欢的科技网站。

## 用户的判断（2026-10-21）

四张最终稿和未选中的豆袋方向都"很一般，没有打动"。比上一轮好在动效和反馈做得好一点、不再那么密集，但没有震撼和惊艳。

结论：探索流程能跳出默认外观，但跳出默认不等于惊艳。剩下的差距不在规则，可能在素材、尺度与动效叙事、首屏信息量，以及挑选环节。
