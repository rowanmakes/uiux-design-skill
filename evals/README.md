# 对照测试

目的：回答"这个技能到底有没有让输出变好"，不靠感觉。

每个简报跑三组，固定简报、素材、模型与时间上限：
1. 无技能（基线）
2. Anthropic frontend-design（或当前在用的方案）
3. uiux-design

记录实际加载的版本、宽窄屏截图（标版本、页面、视口、状态）、修改轮次、盲评分数与理由。
先看差异是否体现在骨架、叙事、素材、状态覆盖上，再看颜色。
完整流程和提示词见 `../docs/playbook.md`。

## 手机与桌面简报（6、7）

先用 HTML 原型测设计判断，这是最便宜的方式；设计定下来后再按实际技术栈实现，那是另一轮测试。
- 手机：截图视口 390×844，浅色、深色各一次；手势和转场必须实际点过、拖过。
- 桌面：常用尺寸 1280×800 和最小窗口尺寸各一次；菜单、快捷键、右键菜单按设计说明逐项核对。
