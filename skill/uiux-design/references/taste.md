## 1. 品味画像

用户的原话：**留白、干净、简约、大气、干练。**

喜欢：Linear（极客精确）、苹果（简约克制）、Spaceship（动效）、Cursor 官网、Grok（高级）、Dishoom、Awwwards 上的获奖作品。
无感：Stripe Press（动效好但"感受不出什么"）、The Pudding、Teenage Engineering（"巨物感，不高级"）。

由此得出的判断标准：**第一眼就感到高级，干净、克制、有分量。** 需要慢慢读才能体会的概念深度、个性很强但不精致的怪趣味，都是加分项，不是核心。

## 2. 最大的风险：安静高级正是模型的默认

三个独立的设计技能都记录了同一个现象：不加约束时，模型会滑向几种固定外观。

- 暖奶油底 + 高反差衬线标题 + 陶土或黄铜色点缀
- 近黑底 + 一个荧光绿或朱红强调色
- 细线报纸风：发丝线、零圆角、密集分栏
- 米色卡片 + 柔和阴影 + 大留白（oil-ui 称之为"被磨回模型默认的安静高级"）

这些外观本身不丑，问题是它们与题材无关地出现，所以一看就是 AI 做的。

**模板装饰清单**（出现就删，除非内容真的需要）：
- 每个标题上方一行全大写小标签
- "A · B · C" 中点连接
- 按钮文字后面的 "→"
- 标题里只给一个词换颜色
- 内容不是序列却编号 01 / 02 / 03
- 紫色渐变、emoji 当图标、左侧彩条圆角卡片
- 三列一模一样的"图标 + 标题 + 一句话"特性卡

**判别一句话：** 换一个同类品牌提同样的需求，你会给出同样的方案吗？会，就是条件反射，不是设计决定。

## 3. 五个词翻译成参数

形容词不能当设计理由。下面每个词都对应可观察、可检查的决定。数值是起点，不是死规定；内容和品牌有理由时可以偏离，偏离要写明理由。

| 词 | 落到界面上 | 起点数值 |
| --- | --- | --- |
| **留白** | 组间距离远大于组内；首屏敢只放一句话和一个画面 | 组内 8–16px，组间 24–48px，区块之间 96–200px（桌面）；区块间距至少是块内间距的 2 倍 |
| **干净** | 只有中性色加一个强调色；不加装饰性边框、阴影、渐变；每条线只做一件事 | 强调色每屏 1–2 处（营销页最多 3–5 处），面积不超过画面 10%；边框用 5%–10% 透明度的细线 |
| **简约** | 每屏一个主角；能删的字删掉；一个界面只用一套图标或不用图标 | 一屏可见字重不超过 3 种；字体家族最多正文 1 + 展示 1 + 等宽 1 |
| **大气** | 标题与正文尺度反差大；主画面满幅或出血；容器够宽 | 营销页字号比例 1.333–1.5，hero 巨字按视口宽度定（3–8 倍正文，用 clamp）；内容宽度 1080–1200px |
| **干练** | 标题短而有力；对齐精确；动效短快不拖沓；按钮写具体动作 | 标题一句话；悬停 150–200ms，弹层 180–220ms，退场约为进场的 75% |

再补三个常被说出口的词：

- **高级：** 先说清是哪一种高级（苹果式的产品崇拜、Linear 式的工程精度、Grok 式的空寂），再决定字体对比、分隔方式、间距尺度和色相数量。只说"高级"什么也没决定。
- **精致：** 公差。对齐到几像素的网格、字距怎么调、阴影最多几级、色相最多几种。
- **克制：** 预算。饱和度预算、强调色面积预算、动效幅度上限。

**颜色的高级感来自低饱和。** 屏幕上刻意压低饱和度，借用的是印刷品的质感记忆。用 oklch 写颜色时的参考：

| 用途 | chroma |
| --- | --- |
| 大面积底色 | 0.01–0.04 |
| 品牌主色 / 强调 | 0.08–0.15 |
| 小面积点睛（按钮、链接） | 0.15–0.22 |

文字不用纯黑 #000，底色不用纯白 #FFF：选带一点色温的近黑和近白，选择要说得出理由（取自产品图、品牌资产或题材的文化色彩）。

## 4. 从参考网站借关系，不借外观

每个参考都有一个只属于它的决定。借的是那个决定背后的**关系**，然后用当前产品的内容重新长出来；不复制它的颜色、字体、Logo 和版式。

| 参考 | 它的核心决定 | 可以借的关系 | 不借 |
| --- | --- | --- | --- |
| 苹果 | 产品像雕塑一样被展示，界面退到看不见 | 黑底与浅灰区块交替形成节奏；唯一的彩色只给可点的东西；标题紧凑像"机加工"出来的 | SF 字体、苹果蓝、胶囊按钮 |
| Linear | 黑暗是原生介质，层级靠明度而不是颜色 | 越深越底层、越亮越浮起的明度堆叠；几乎看不见的边框；介于常规和中等之间的字重做强调 | 紫色强调、Inter 加特定字形变体 |
| Grok（xAI） | 用"缺席"说话：无渐变、无插画、无彩色 | 一个元素放到极端尺度，其余全部让路；锐利直角；按钮像终端命令 | 等宽巨字这一具体手法 |
| Cursor | 暖纸色加三种字体，像高级出版物 | 整套系统统一偏暖；展示、正文、代码三种声音分工明确 | 它的定制字体和橙色 |
| Spaceship（spaceship.com，域名与主机） | 一个主题贯穿全站：太空隐喻从首屏标语、产品命名一直延伸到动效；首屏直接就是主任务（域名搜索加价格） | 主题要从文案、命名、动效一起长出来，而不是只贴一层背景；首屏放用户来做的那件事；用动画演示流程，代替一段文字说明 | 太空隐喻本身、插画人物 |
| Dishoom | 文化细节极其具体 | 从题材自己的历史、地点、材料里取素材和语气 | 孟买咖啡馆元素 |

上表前四行的观察来自第三方从网站代码中提取的设计规格（tasteful-ui 仓库收录），可能已经过时。Spaceship 一行来自 2026-10-21 读取的页面结构和文案，动效本身没有亲眼看到。用之前打开官网看一眼当前样子，不凭记忆。

## 5. 安静但不平庸：力气花在哪

安静高级要成立，必须有真实的决定撑着，而不是靠空。力气集中花在下面几处，其余全部安静。

**1. 骨架。** 写文案之前先定首屏结构。左右分栏（左边标题说明按钮，右边一张图）是模型最顽固的默认，一轮最多用一次。其他选择：

| 骨架 | 首屏样子 |
| --- | --- |
| 居中单一物件 | 一个物件或一句话居中，四周大面积空白 |
| 满版图像压字 | 一张图占满首屏，标题压在安全区 |
| 画面即界面 | 首屏就是产品界面或实物本身 |
| 满版文字 | 字大到占满首屏、跨出边缘或被裁切 |
| 通栏上下堆叠 | 通栏大标题横跨整个宽度，下面紧接内容 |
| 纵排或斜向 | 竖排、斜切，打破从左到右的阅读 |

**调性决定音量，骨架决定结构。** 安静的产品一样可以把一句话放在空白首屏正中，不需要退回左右分栏。

**2. 一个主角。** 每屏只有一个元素最突出。把画面模糊 8px，应该只剩一个块面最醒目；相邻层级至少在一个维度上（大小、字重、对比、面积）差 1.5 倍。

**3. 一处记忆点。** 全页只在一两处集中发力：一个关键动作的反馈、一个让人意外的尺度、首屏的一次出场。它要说得出来自这个产品的什么。

**4. 真实的东西当主角。** 产品真正交付的东西（一张报表、一段真实界面、一件实物）比任何口号和图标都有说服力。

**5. 示例数据像真的。** 写 1,238 位用户、+1.83%、"昨天 16:12"，不写 1,000、+10%、"2 小时前"。

## 6. 素材不足时：高级的空 vs 寒酸的空

苹果和 Grok 的留白有分量，是因为留白中间放的是顶级素材或极端的尺度。同样的留白，中间只放一行普通标题和三张卡片，就是寒酸的空。

**检验：** 留白里放的东西，单独拿出来值不值得被这么多空间围着？不值得，要么换素材，要么收紧留白。

没有好照片时，按顺序考虑：

1. **真实的产品画面或内容：** 界面截图、作品、实物照片。
2. **字即图像：** 巨字、裁切、竖排。字本身成为画面，而不是"标题 + 正文"的默认排法。
3. **数据即图像：** 把内容里的数字画成量（长度、面积、个数），而不是三个大数字卡片。
4. **克制的程序化材质：** 细腻的噪点、光影、几何，只在和题材有关时用。
5. **能生图时：** 先为每个方向出一张主视觉探针图，选定后再生成正式素材。
6. **都没有：** 诚实占位，并在交付时说明缺什么。不用通用插画和"灵感图"凑数。

**真图诚实性测试：** 去掉这张图，信息有没有损失？没有，它就是装饰，不加。

## 7. 中文规则（覆盖西文参数）

苹果、Linear 那套"大标题负字距、行高 1.05"是为西文设计的。中文界面上，下面的规则优先。

| 项 | 规则 |
| --- | --- |
| 字距 | 正文 0 至 0.05em；标题 0；60px 以上的巨字最多 -0.02em。**不要套用西文标题的负字距**，汉字是满格方块，收紧会笔画相撞 |
| 行高 | 巨字 1.1–1.25；多行标题 1.2–1.4；正文 1.6–1.8；行越长行高越大 |
| 行长 | 正文每行 22–38 字，最佳 28–32 字（约 `max-width: 36em`） |
| 字号 | 阅读型正文 16–18px；产品界面正文 14–16px；不用 12px 以下的小字营造"精致" |
| 字体 | 正文只在宋、黑、楷里选（思源宋体、思源黑体、霞鹜文楷等）；一页最多两个中文字体家族 |
| 混排 | `font-family` 西文字体在前、中文字体在后，数字和字母由西文字体接住；表格数字加 `tabular-nums` |
| 强调 | 中文没有斜体。强调用字重、颜色或着重号；全局加 `font-synthesis: none` |
| 断行 | 标题用 `text-wrap: balance`；"38 秒"这类数字加单位、不可拆的词用不换行包起来；行尾孤零零一两个字算缺陷 |
| 标点 | 引号用「」；`line-break: strict` 避头尾 |

## 8. 动效：有含义才动

用户喜欢的动效（Spaceship、苹果）都在讲故事。每一个动画都要能用一句话回答"它传达了什么"：层级、顺序、反馈还是状态变化。答不上来就删。

- **营销页：** 可以有一段由滚动驱动的叙事和克制的区块出场；首屏一次有分量的出场。不要弹跳、彩纸、无意义的漂浮。
- **产品界面：** 只用于反馈和状态变化；悬停、弹层、乐观更新。不做滚动特效和视差。
- **始终：** 尊重 `prefers-reduced-motion`；只过渡 transform、opacity 等，不写 `transition: all`。

## 9. 按页面类型调音量

同一个品味，在不同页面上"音量"不同。

| 页面 | 音量 | 做法 |
| --- | --- | --- |
| 官网、发布页、作品集 | 高 | 本文件全部适用；骨架大胆，记忆点明确 |
| 文档、文章、报告 | 中 | 留白与排印为主，节奏优先；记忆点放在图表或引言 |
| 后台、工具、表单 | 低而稳 | 高级感来自精确和状态完整：对齐、层级、密度恰当、每个状态都想好了。不加营销式大标题、渐变和动效 |

后台的"惊艳"是"清楚得让人意外"，不是视觉冲击。

## 10. 交付前自检

- [ ] **换名字测试：** 把产品名换成竞争者，页面几乎不用改吗？是就重做。
- [ ] **默认外观检查：** 是否落进了第 2 节的几种默认外观？如果是，能说出来自这个产品的理由吗？
- [ ] **模板装饰：** 第 2 节清单里的装饰都删了吗？
- [ ] **模糊测试：** 模糊 8px 后，每屏只剩一个主角吗？
- [ ] **空的检验：** 每片留白中间放的东西撑得住吗？
- [ ] **过头检验：** 去掉那个最大胆的手法，信息更清楚了吗？清楚了就是过头。
- [ ] **中文检查：** 没有负字距、行高够、没有孤字、没有假斜体？
- [ ] **动效检查：** 每个动画都能说出它传达什么吗？

## 11. 来源

本文件的规则综合自以下仓库（2026-10-21 拉取的版本），数值为它们给出的经验起点，未经本项目测试验证：

- oil-ui（`7002e1a`）：模糊词翻译、首屏骨架、默认"安静高级"的警告、记忆点、示例数据、中文标题行高

- tasteful-ui（`159ccd4`）：苹果、Linear、xAI、Cursor 的设计规格拆解（第三方提取）
