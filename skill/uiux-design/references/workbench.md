适用：用户每天连续使用几个小时的专业工具，例如画布与节点编辑器、生图与素材管理、项目管理、代码与数据工具（参照 Linear、Figma、VS Code、ComfyUI 一类）。先读 `app.md` 第 5 节的桌面约定，本文件在其上补充工作台特有的部分。

## 1. 工作台的高级感从哪来

营销页靠第一眼的冲击，工作台靠第一百个小时的顺手。用户不会每天欣赏界面，他们会每天用几千次同样的操作。所以这里的"惊艳"是：

- **快：** 每个操作 100ms 内有反馈，长任务不阻塞界面。
- **准：** 对齐、层级、状态在每个角落都一致，没有一处是临时凑的。
- **不打扰：** 界面退后，用户的内容（作品、数据、代码）是主角。
- **记得住：** 关掉再打开，一切都在原来的位置。

## 2. 五个词在工作台里的意思

| 词 | 在工作台里 |
| --- | --- |
| **留白** | 不是大片空白，而是界面框架安静：面板边界极淡，内容区周围不堆工具；内容本身可以很密 |
| **干净** | 框架只用中性色，颜色留给内容和状态；一个强调色只标当前选中和主操作 |
| **简约** | 默认只露出最常用的东西，其余按需展开或在命令面板里；每个面板只做一件事 |
| **大气** | 主内容区（画布、网格、编辑器）拿到尽可能多的空间；框架能收起，有专注模式 |
| **干练** | 键盘优先，快捷键就近显示；控件紧凑但不挤；文案是动词和名词，不解释 |

## 3. 布局：面板系统

典型结构：

```
┌──────────────────────────────────────────────┐
│ 工具栏 / 标题栏                                 │
├────────┬─────────────────────────┬───────────┤
│ 侧栏    │ 主区域（画布 / 网格 / 编辑器） │ 检查器     │
│ 项目    │                          │ 当前对象   │
│ 导航    │                          │ 的属性     │
├────────┴─────────────────────────┴───────────┤
│ 底部面板（队列 / 日志 / 控制台），可收起            │
├──────────────────────────────────────────────┤
│ 状态栏（连接、资源占用、后台任务）                  │
└──────────────────────────────────────────────┘
```

- 每个面板可调宽度、可收起，并记住用户的设置；窄窗口时先收检查器，再收侧栏。
- 检查器内容跟着选中对象变；没有选中时显示有用的东西（当前项目概况或快捷提示），不是空白。
- 后台任务的进度放在状态栏或底部面板，不弹窗打断。
- 起点尺寸：侧栏 200–280px，检查器 260–340px，控件高度 28–36px。

## 4. 画布

有画布或节点编辑器时，用户会默认它遵守行业通行的操作：

- 平移：空格加拖动、触控板双指滑动、鼠标中键；缩放：触控板捏合、Ctrl / Cmd 加滚轮、快捷键放大缩小、一键适配全部和缩放到选中。
- 选择：点选、框选、Shift 加选；选中态清楚，悬停态与选中态不同。
- 对齐与吸附：拖动时给对齐参考线，吸附可以临时关闭（通常按住一个修饰键）。
- 大画布提供小地图或概览。
- 撤销 / 重做覆盖所有操作，粒度合理（拖动一次算一步，不是每个像素一步）；有可查看的历史。
- 尽量非破坏性：原图、原参数保留，修改可以回退。

## 5. 键盘与效率

- **命令面板（Cmd / Ctrl + K）：** 所有命令可搜索、显示快捷键；最近用过的排前面。
- **快捷键就近显示：** 菜单项、按钮提示里写出快捷键，帮助用户从鼠标过渡到键盘。
- **列表导航：** 上下键或 J / K 移动，回车打开，Esc 返回。
- **批量操作：** 多选后可统一操作，有明确的"已选 N 项"状态。
- **焦点：** 键盘焦点始终可见，弹层关闭后焦点回到原处。

## 6. 颜色与密度

- **框架用中性灰。** 做图像、视频、设计类工作时尤其重要：框架带色会影响用户对作品颜色的判断。
- **状态色压低饱和度：** 成功、警告、危险、信息四种，屏幕要被盯 8 小时，不用鲜艳色块。状态色用在文字、小圆点和细边上，背景保持中性。
- **深色与浅色都要成立；** 图像类工作台通常默认深色，让作品更突出。层级靠明度：越浮起越亮。
- **字号：** 正文 13–14px，表格可以 12px；页面标题 18–20px，区块标题 14–15px。中文不低于 12px。
- **数字：** 所有数字列和计时用等宽数字（`tabular-nums`）并右对齐；ID、哈希、种子值、时间戳用等宽字体。
- **间距：** 4 / 8 网格，常用 4、8、12、16、24。

## 7. 状态与持久化

- 关闭后重新打开，恢复窗口布局、打开的项目、滚动位置、选中对象。
- 自动保存；有版本或快照可以回到之前。
- 长任务（生成、导出、同步）后台进行，可以取消、重试，失败不丢输入。
- 断开连接（远端服务、本地引擎没启动）时清楚告知，并给出恢复路径；已有内容仍可浏览。
- 空状态写一句下一步做什么，附上快捷键。

## 8. 不要做的事

- 营销页的东西：大标题、滚动出场动画、装饰插画、大片留白的卡片网格。
- 每个指标一张卡片、每张卡片一个彩色顶边。
- 全黑的侧栏配荧光强调色（AI 和开发工具最常见的模板外观）。
- 用颜色区分几乎所有东西，导致真正的状态色淹没其中。
- 隐藏的快捷键、只能鼠标完成的操作。
- 列表区域里的入场动画（长列表会卡）；排序、筛选、拖动列宽要即时。

## 9. 交付前自检

- [ ] 主内容区拿到了最大的空间吗？框架能收起吗？
- [ ] 每个操作都有 100ms 内的反馈吗？长任务不阻塞界面吗？
- [ ] 命令面板能找到所有操作吗？快捷键在界面上看得到吗？
- [ ] 画布的平移、缩放、选择、撤销符合用户习惯吗？
- [ ] 框架是中性色，颜色留给内容和状态了吗？
- [ ] 关掉再打开，一切都在原位吗？
- [ ] 窄窗口和最小窗口尺寸下还能用吗？
