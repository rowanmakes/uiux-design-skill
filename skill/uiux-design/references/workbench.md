# 桌面工作台：极客感

适用：每天连续用几个小时的专业工具，例如画布与节点编辑器、生图与素材管理、项目管理、代码与数据工具。本文件自成一体，做工作台不需要再读 `app.md`。

## 1. 品味

用户确认（2026-10-21）：官网要电影感，工作台要**极客风**，两者不混用。参照 Linear、Raycast 的客户端：精确、快、键盘优先、系统是活的。把官网的氛围场景搬进工作台，或把工作台的信息面板搬上官网，都不对。

这里的惊艳不在第一眼，在用到第一百个小时还顺手：
- **快：** 每个操作 100ms 内有反馈，长任务不阻塞界面。
- **准：** 对齐、层级、状态处处一致。
- **不打扰：** 框架退后，用户的作品、数据、代码是主角。
- **记得住：** 关掉再打开，窗口布局、打开的项目、选中对象都在原位。

## 2. 第一轮测试暴露的问题（简报 07，两组都只有 2.8–2.9 / 5）

逐条确认，做完要实际操作，截图证明不了：
- **键盘能完成主任务：** 命令面板（Cmd / Ctrl + K）能找到所有命令并显示快捷键；列表上下键移动、回车打开、Esc 返回；焦点始终可见，弹层关闭后回到原处。
- **小窗口能用：** 至少检查常用尺寸（如 1280×800）和最小窗口尺寸；窄了先收检查器，再收侧栏。
- **反馈和数据一致：** 队列里显示"完成"的就真的有结果；计数、状态、进度和实际数据对得上。

另外，第一轮里我们这组没在时限内交付，记录怀疑和要读的文件太多有关（未确认）。所以工作台先把主流程和上面三条做扎实，再加别的。

## 3. 布局

常见结构：工具栏 · 侧栏 · 主区域（画布 / 网格 / 编辑器）· 检查器 · 可收起的底部面板（队列、日志）· 状态栏（连接、资源、后台任务）。
- 主内容区拿到尽可能多的空间；面板可调宽、可收起，并记住设置；有专注模式。
- 检查器跟着选中对象变；没选中时显示有用的东西，不是空白。
- 后台任务进度放在状态栏或底部面板，不弹窗打断。

## 4. 颜色与密度

- 框架用中性灰；做图像类工作时尤其重要，框架带色会影响对作品颜色的判断。颜色只留给内容、状态和当前选中。
- 状态色压低饱和度，用在文字、小圆点、细边上，背景保持中性。
- 图像类工作台通常默认深色；层级靠明度，越浮起越亮。
- 数字列和计时用等宽数字并右对齐；ID、种子值、时间戳用等宽字体。中文不低于 12px。

## 5. 套壳客户端不能"一看就是网页"

Electron、Tauri 这类套壳最常见的失败：
- 原生菜单栏包含所有命令，标准快捷键都能用（复制、粘贴、撤销、设置、关闭窗口）。
- 窗口控件跟随系统（macOS 左上、Windows 右上）；自定义标题栏保留拖动区域和双击行为。
- 右键菜单是应用自己的，内容和当前对象相关，不弹出浏览器菜单。
- 启动先显示骨架而不是白屏。
- 优先用系统材质（macOS 半透明、Windows Mica），不用网页模仿一层毛玻璃。

## 6. 不要做的事

- 营销页的东西：大标题、滚动出场动画、装饰插画、大片留白的卡片网格。
- 每个指标一张卡片、每张卡片一个彩色顶边。
- 全黑侧栏配荧光强调色（AI 和开发工具最常见的模板外观）。
- 只能用鼠标完成的操作；长列表里的入场动画。
