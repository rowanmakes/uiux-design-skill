## 4. 核心设计决定与理由

1. **北极星与四幕连续镜头叙事（遵循 `taste.md` 1.5 节）**：
   - 亲眼查看场景 C 的 4 张图片后发现，它们共享完全一致的远山天际线、右侧落日光源与左三分之一深林暗影安全区，前景随景深依次从**山脊咖啡红果（`hero-02.webp`）→ 云雾高坡梯田（`01.webp`）→ 暮光木质高架晒床（`02.webp`）→ 林间木桌上的 200g 牛皮纸鲜烘豆袋与热气咖啡杯（`03.webp`）**推进。
   - 因此不把图片切碎塞进传统上下图文块或三列电商卡片，而是建立 `position: fixed` 的全屏电影级主舞台（`.cinema-stage`），由真实页面滚动（`window.scrollY`，全页 `400vh`）连续驱动四幅画面的 `smoothstep` 交叉溶解与缓慢推镜视差。
2. **首屏绝对克制（遵循 `taste.md` 1.5 与第 3 节）**：
   - 首屏只有 1 个主视觉（`hero-02.webp`）、1 句核心主张（`豆子的产地和处理法，自己会说话。`）、1 个主动作按钮（`走入半山当季豆单`），左上角暗林安全区静置低对比度品牌标识 `半山烘焙 · 成都`。
   - 首屏零价格卡片、零跑马灯、零统计条带、零虚假徽章；所有文案压在左三分之一深林暗部，完整让出右侧落日、山脊与咖啡果。
3. **代码叠加的四层物理空气与光影（参数严格落在 `taste.md` 1.5 区间）**：
   - **有来源的光**：对齐画面右上落日坐标（`left: 78.5%; top: 19%`），叠加径向暖琥珀光源呼吸（`.sun-source-glow`，周期 `8s`，落在 6–10 秒区间）与斜射霞光漫射层（`.sun-rim-wash`，周期 `7.6s`）。
   - **缓慢山雾与蒸汽**：三层高斯模糊暖雾带（`.mist-band-1/2/3`）横跨山谷与木桌，周期分别为 `42s`、`54s`、`36s`（严格落在 30–60 秒区间），肉眼只感空气流动而不抢戏。
   - **稀疏逆光微粒**：12 颗逆光浮升微尘（`.mote`），沿斜射光束缓慢上浮，单周期 `8.6s–13.6s`（严格落在 8–14 秒区间）。
   - **胶片颗粒**：内联 SVG `feTurbulence` 噪点叠层（`.film-grain`），`opacity: 0.14`（严格落在 0.08–0.25 区间）。
4. **豆单与订阅融入场景，不做独立白卡或生硬弹窗**：
   - 第一幕（`01.webp` 云雾高坡梯田）：原样呈现固定品牌介绍全文，并在梯田旁以左侧单边细线风土档案形式呈现第一支豆子「云雾水洗（埃塞俄比亚 耶加雪菲 · 水洗 · ¥68 / 200g）」，配浅中烘风味光谱与指向梯田的视觉引线（`.scene-sightline`）。
   - 第二幕（`02.webp` 木质高架晒床）：在晒床实景旁呈现「火塘日晒（巴西 喜拉多 · 日晒 · ¥58 / 200g）」与「山脊蜜处理（哥伦比亚 惠兰 · 蜜处理 · ¥72 / 200g）」，用户可在场景内直接点击选入当期豆袋。
   - 第三幕（`03.webp` 林间木桌 200g 牛皮纸豆袋与热杯）：将订阅方式（`按月寄送，每期 1 袋 200g`）、订阅价格方案（`¥62 / 月起 单袋订阅价` / `¥118 / 月 双袋尝鲜组合`）、可选节奏（`每 2 周 / 每月 / 每 6 周`）、当期豆款切换及收件通知登记整合在同一木桌场景左侧暗部，形成从看风土到订豆子的完整交互闭环。
5. **零外部网络依赖与本机字体栈**：
   - 经检测本机环境已安装 `Noto Serif SC`、`Source Han Serif SC`、`Noto Sans SC`、`Georgia` 等字体，滚动与动效由原生 `requestAnimationFrame` + CSS 合成属性（`transform`、`opacity`）驱动，不引入外部 CDN，确保 `file://` 下 `assetsReady` 毫秒级完成且 `failedRequests` 为零。

## 5. 多轮录屏、接触表与截图观察及修改记录

### 5.1 视频观测方法与诚实限制说明
- **观测方式**：由于当前图像读取工具（`read_file`）不支持直接流式渲染 `.webm` 视频，本运行编写了 `runs/e2-C-agy/inspect-video.mjs`，在真实 Chromium 浏览器中通过同目录 `file://` 播放器页面加载每段 `.webm` 录屏，调用 `<video>.play()` 实际播放验证（`playedOk: true`），并在 `0.5s, 2.5s, 4.5s, 6.5s, 8.5s, 10.5s, 12.5s, 14.5s, 16.5s, 18.5s, 21.0s, 23.5s` 共 **12 个连续时间点**（覆盖开头 3s 静置、20s 匀速滚动全程及末尾 2s 静置）逐帧截取画面并拼合为 `1440x900-contact-sheet.png` 与 `390x844-contact-sheet.png`，配合每轮 8 张全分辨率滚动位置截图（`01-start`、`02-third`、`03-two-thirds`、`04-end`）全部亲眼查看。
- **限制说明**：接触表为上述 12 个离散采样时刻的连续帧网格，而非 60fps 逐帧人眼实时观看；但已完整覆盖四幕停留与全部三次跨幕过渡区间。

### 5.2 初版（`runs/e2-C-agy/recordings/initial/`）观察与发现的问题
运行 `node scripts/scroll-record.mjs runs/e2-C-agy/output/index.html runs/e2-C-agy/recordings/initial` 并查看全部 8 张截图与 2 张 12 帧接触表后，发现以下 4 个具体视觉问题：
1. **桌面端前景框体偏“卡片感”**：`1440x900-02-third.png` 与 `03-two-thirds.png` 中，左三分之一文字区使用了四周边框的圆角半透明盒，有轻微模板卡片感，不够像融入山林暗部的镜头旁白。
2. **跨幕过渡边缘残影**：在 `1440x900-02-third.png` 顶部及接触表 `t=10.5s`、`t=16.5s` 帧中，上一幕/下一幕容器因设置了最低 `0.15` 不透明度，在视口上下边缘留下了淡淡的半透明残影边角。
3. **移动端首屏品牌标识位置跑偏**：在 `390x844-01-start.png` 中，由于移动端 `.act-hero` 使用了 `align-items: flex-end`，导致顶部品牌标识「半山烘焙 成都」被推到了右上角落日强光区，违背了放在左上暗部安全区的设计意图。
4. **移动端下部面板偏高**：在 `390x844-03-two-thirds.png` 与 `04-end.png` 中，下部文字与订阅区占用了约 68% 视口高度，遮挡了 `02.webp` 的晒床主体与 `03.webp` 的木桌牛皮纸豆袋。
