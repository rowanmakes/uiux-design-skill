## 二、逐方向看图自评（对照 `test/refs/` 三问）

### 1. 方向一（`d1-v1` · 骨架：画面即界面）
- **已看截图**：`runs/e1-D-1/directions/shots/d1-v1/wide-fold.png`、`narrow-fold.png`
- **对照 `test/refs/` 具体观察**：
  - 对照 `test/refs/linear.app/01-fold.png` 与 `cursor.com/01-fold.png`：Linear 与 Cursor 最打动人的是“产品功能界面本身就是首屏主视觉”，克制的 1px 暗色分割线（`rgba(236,239,244,0.09)`）、高对比几何无衬线大标题与等宽字体参数相得益彰。
  - 在 `d1-v1/wide-fold.png` 中，1440×900 首屏直接呈现为一个三栏式「浅中烘风味光谱与按月订阅调阅台」：左栏并列 `01 云雾水洗 / 02 火塘日晒 / 03 山脊蜜处理` 三款豆单，中栏以 48px 暗格坐标网绘制 SVG 酸甜平衡曲线与三颗风味节点（`茉莉花香 / 柠檬酸质 / 红茶尾韵`），右栏直接配置单袋（`¥62 / 月起`）/ 双袋（`¥118 / 月`）及寄送节奏（`每 2 周 / 每月 / 每 6 周`），并实时生成底部的「当期豆袋封签预览」。
  - **看图发现的具体瑕疵（不掩盖问题）**：
    1. 在 `d1-v1/wide-fold.png` 中栏 SVG 光谱图左上角，背景刻度文字 `HIGH CLARITY / 花果香气段` 的右端（约 `x=140, y=36`）与第一个风味节点标签框 `茉莉花香`（`x=135, y=68` 上移 `-34`）左边缘发生了轻微视觉擦碰；同理，第二条刻度线文字 `SWEETNESS & ACIDITY / 酸甜平衡段（浅中烘核心区）` 被青绿色曲线穿过，阅读略有干扰。
    2. 在 `d1-v1/narrow-fold.png`（390×844）中，顶部品牌名 `半山烘焙` 因左侧胶囊宽度挤压断成了两行（`半山烘` / `焙`），需要在后续深化时加 `white-space: nowrap` 保持品牌名完整。
- **逐题回答**：
  1. **会有人想截图收藏吗？**
     会。深曜石底（`#090A0D`）配茉莉青柠绿（`#7EE2B8`）的交互式咖啡风味光谱仪与实时豆袋封签生成台，打破了人们对咖啡店官网“要么农庄照片、要么米黄文艺卡片”的刻板印象，极客感与干练度接近 `linear.app`。
  2. **把店名换成另一家咖啡店，几乎不用改吗？**
     不能直接套用。因为整套中栏光谱曲线的三个锚点、左栏三档处理法（水洗/日晒/蜜处理）与右栏“每期 1 袋 200g · 偏浅中烘 · 出炉当日标注烘焙日期”的封签字段，完全咬合在半山烘焙“只做订阅制浅中烘三支豆”的业务结构上。
  3. **是不是又是那种千篇一律的样子？**
     不是。它完全避开了暖米色纸底+衬线标题+陶土点缀的默认外观，也没有堆砌三张均分圆角白卡，而是用“画面即界面”的极客精确感诠释“豆子的产地和处理法自己会说话”。
- **是否重做**：**不重做骨架**（0 次重做）。其中栏坐标文字擦碰与窄屏品牌名换行问题，记录并在第五步深化为 `output/index.html` 时彻底修正。

### 2. 方向二（`d2-v1` · 骨架：居中单一物件）
- **已看截图**：`runs/e1-D-1/directions/shots/d2-v1/wide-fold.png`、`narrow-fold.png`
- **对照 `test/refs/` 具体观察**：
  - 对照 `test/refs/apple.com/01-fold.png` 与 `grok.com/01-fold.png`：Apple 与 Grok 的核心张力来自大面积纯净留白与居中单一焦点的克制关系。

  - **看图发现的具体瑕疵**：
    1. 在 `d2-v1/wide-fold.png` 中央豆袋封签的右上角，品牌小字 `BANSHAN ROASTERS · 成都` 的末尾“成都”二字与右对齐的处理法标签 `水洗` 在 `x=188, y=114` 处发生了文字重叠（渲染成“成水洗”）。

     不是。冷白雾底+冷杉青色+居中单体实物图避开了常规横幅加三卡片的套路，整体干净克制。
- **是否重做**：**不重做骨架**（0 次重做）。作为方向二保留其“居中单一物件”的探索成果与截图证据。

## 三、最终选择哪个方向深化为完整首页（`output/index.html`）及理由

### 选定深化方向：**方向一（`d1` · 画面即界面：浅中烘风味光谱与按月订阅调阅台）**，并融合方向三的“云·火·山”山地处理法切片基因

### 选择理由：
1. **最契合 `test/refs/README.md` 中的用户核心审美偏好**：
   用户明确喜欢 **Linear（极客、精确）、Apple（简约克制）、Spaceship（动效与主题贯穿全站）、Cursor、Grok（高级）、Dishoom（文化细节具体）**，且追求 **“留白、干净、简约、大气、干练”**。方向一（`d1`）以曜石深色精密界面承载“豆子的产地和处理法自己会说话”，既有 Linear / Cursor 的极客精准度，又通过大面积干净留白与克制的 1px 结构线保持了高级感。
2. **最能解决“没有照片”的简报痛点，把劣势转化为独特品牌语言**：
   简报明确指出“目前只有名字‘半山烘焙’、几句介绍和三款豆子的信息，没有照片”。与其用空洞的色块假装照片，方向一直接将**三支豆子的产地、处理法（水洗 / 日晒 / 蜜处理）与三段风味描述**转化为可交互、可视化的「浅中烘风味光谱与酸甜醇度坐标系统」以及「200g 实时出炉豆袋封签」，让数据与风味本身成为最耐看的主视觉。
3. **深化计划（从首屏 `d1` 拓展为完整首页 `output/index.html`）**：
   - **修复 `d1-v1` 看图发现的两处细节瑕疵**：调整光谱 SVG 刻度文字位置，彻底消除与 `茉莉花香` 节点框的擦碰；给顶部品牌名加 `white-space: nowrap` 避免窄屏断行。
   - **贯穿全站的四大章节（保持足够留白与呼吸感）**：
     1. **首屏（01 / 风味光谱与订阅调阅台）**：交互式三豆光谱曲线 + 实时豆袋封签预览。
     2. **第二屏（02 / 品牌理念与浅中烘尺度）**：完整呈现固定品牌介绍原文，用三组精确的 SVG 处理法切面图解（「水洗·澄澈花果」「日晒·火塘醇厚」「蜜处理·山脊焦糖甜感」）解释为什么“豆子的产地和处理法自己会说话”。
     3. **第三屏（03 / 当期三款订阅豆单全览）**：以极具呼吸感的建筑级卡片并列展示「云雾水洗（¥68 / 200g）」「火塘日晒（¥58 / 200g）」「山脊蜜处理（¥72 / 200g）」的完整产地、处理法、前中后调风味与订阅联动按钮。
     4. **第四屏（04 / 按月订阅方案与寄送节奏配置器 + 页脚）**：清晰对比「单袋订阅价 ¥62 / 月起」与「双袋尝鲜组合 ¥118 / 月」及「每 2 周 / 每月 / 每 6 周」三种寄送节奏，页脚仅出现一次“这是样例”说明。
