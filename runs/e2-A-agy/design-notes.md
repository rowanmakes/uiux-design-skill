# 半山烘焙 (Banshan Roastery) — 设计说明与场景架构 (Design Notes)

## 1. 视觉与体验北极星 (North Star)
- **主题定位**：成都小型精品咖啡豆烘焙工作室「半山烘焙」官网首页（只做订阅制卖豆，小批量浅中烘，按月寄送到家）。
- **核心隐喻与空间轨迹**（遵循 `skill/uiux-design/references/taste.md` 第 1.5 节「场景即页面 / 电影式数字体验」）：
  - 页面不是静态信息卡片墙，而是一镜到底的空间推镜：**从破晓前的成都半山雾海（首屏 `hero-01.webp` & 第一幕 `story-01.webp`）→ 顺着山脊推近林间微亮暖窗的木屋烘焙间（第二幕 `story-02.webp`）→ 走入烘焙间窗前厚木桌、200g 牛皮纸豆袋与冒着热气的粗陶咖啡杯旁（第三幕 `story-03.webp` & 订阅定制台 `#subscribe-desk`）**。
- **色彩与光影关系**：
  - 环境底色采用低饱和冷黛山夜色（`oklch(0.11 0.022 252)` 至 `oklch(0.15 0.024 248)`），与远山木屋窗内透出的暖琥珀烘焙炉火光（`oklch(0.75 0.14 68)` / `oklch(0.84 0.12 74)`）形成冷暖色温递进。
  - 文字严格排印在画面左侧 1/3 的深色山林与室内暗部留白区（响应 `test/e2/images/A/selection.json` 的 `titleSafeThird` 准则），绝不遮挡右侧的暖窗、烘焙机、200g 豆袋与咖啡杯。

## 2. 首屏纪律与反膨胀法则
- **首屏 (`#top`)**：
  - 全视口主视觉：`./assets/hero-01.webp`（复制自 `test/e2/images/A/candidates/hero-01.webp`）。
  - 左上角克制文字标识：`半山烘焙`。
  - 唯一核心主张：`豆子的产地和处理法，自己会说话。`
  - 唯一主行动：`走进半山烘焙间`（锚点推进至 `#narrative`）。
  - **严格克制**：无顶部导航栏、无统计数字/徽章、无特性卡片；豆单、价格与订阅规则全部置于首屏之下。

## 3. 真实滚动驱动的三幕叙事与开放式排印账页
- **滚动叙事 (`#narrative`)**：
  - 由原生 `window.scrollY` 实时计算 `globalProgress` 与 `trackProgress`，驱动 `./assets/story-01.webp` → `./assets/story-02.webp` → `./assets/story-03.webp` 的景深推镜（`scale` + `translate3d`）与平滑叠化。
  - 三款固定当期咖啡豆与订阅说明直接以开放式排印账页（无四周封闭卡片框，仅用左侧单根琥珀细线与水平发丝线分隔）生长在场景左侧暗部留白中：
    1. 第一幕（`story-01.webp`）：品牌介绍原文 + 第一支豆「云雾水洗」（埃塞俄比亚 耶加雪菲 / 水洗 / 茉莉花香、柠檬酸质、红茶尾韵 / `¥68 / 200g`）。
    2. 第二幕（`story-02.webp`）：第二支豆「火塘日晒」（巴西 喜拉多 / 日晒 / 巧克力、烤坚果、低酸醇厚 / `¥58 / 200g`）+ 第三支豆「山脊蜜处理」（哥伦比亚 惠兰 / 蜜处理 / 红苹果、焦糖甜感、奶油口感 / `¥72 / 200g`）。
    3. 第三幕（`story-03.webp`）：按月寄送（每期 1 袋 200g）、单袋订阅价 `¥62 / 月起`、双袋尝鲜组合 `¥118 / 月`、可选节奏 `每 2 周` / `每月` / `每 6 周`。
- **多层自然动效**：
  - 双层山谷云雾缓慢漂移（`44s` / `54s`）、木屋暖窗方向光柔和呼吸（`8s`）、第三幕杯口水汽升腾（`38s`）、零星空气微尘（`8.6s–13.8s`）及全屏 SVG `feTurbulence` 胶片颗粒层（`opacity: 0.14`）。
  - 在 `prefers-reduced-motion: reduce` 模式下，所有动画停用，粘性滚屏舞台自动展开为三幕独立静态图文背景章节。
- **诚实规则**：
  - 全页不编造任何客户评价、媒体背书或销量数据；样例与生成图说明仅在页脚 `.site-footer` 出现唯一一次。
