菜单、快捷键与右键菜单设计规范（Windows & macOS 双平台适配）

针对 Electron / Tauri 本地 AI 生图桌面客户端的原生交互架构说明（可在上方工作台直接点击或右键体验）

桌面端交互设计文档
一、顶部应用菜单设计 (Application Menu) Windows 窗口内嵌 / macOS 顶栏

遵循桌面端高频效率原则，分为五大一级菜单；Windows 下支持 Alt+字母 助记键唤醒，macOS 下映射至系统全局 Menu Bar：

一级菜单 核心菜单项与职责
文件 (F) 新建项目、打开本地项目目录、导出当前选中图片的参数配置 (JSON)、在系统资源管理器/访达中定位输出目录。
编辑 (E) 复制提示词 (Prompt)、复制负面提示词、复制种子 (Seed)、从剪贴板粘贴并解析生图参数元数据。
任务 (T) 按当前检查器参数发起生成、锁定种子重新采样、重试失败任务（如显存不足的 task-b1）、暂停/恢复本地队列、清空已完成项。
视图 (V) 切换网格缩略图尺寸、按状态筛选（生成中 / 排队中 / 失败 / 已完成）、展开或收起右侧参数检查器与底部队列面板。
窗口/帮助 最小化、全屏切换、打开快捷键速查表、本地显存占用诊断与分块采样 (Tiled VAE) 恢复建议。
二、快捷键设计 (Keyboard Shortcuts) Win / macOS 双键位映射

围绕「改参 → 投递队列 → 检视网格 → 复用种子」核心闭环设计，支持单键检视与组合键执行：

功能动作 Windows macOS
按当前参数加入生图队列 Ctrl + Enter ⌘ + Return
锁定当前种子重新生成 Ctrl + R ⌘ + R
重试失败队列任务 (task-b1) Ctrl + Shift + R ⇧ + ⌘ + R
复制当前选中图片提示词 Ctrl + C ⌘ + C
复制当前选中图片种子 (Seed) Ctrl + Shift + C ⇧ + ⌘ + C
在资源管理器/访达中定位 Ctrl + Shift + O ⇧ + ⌘ + O
暂停 / 恢复本地任务队列 Space Space
快速切换样例参数 1 / 2 / 3 1 / 2 / 3 1 / 2 / 3
新建本地项目 Ctrl + N ⌘ + N
