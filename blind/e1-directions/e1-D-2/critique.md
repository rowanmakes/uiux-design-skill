## 二、三个方向逐一审视与三问回答

### 方向一：`d1.html`（骨架：画面即界面 · 截图：`shots/d1-v1/wide-fold.png`, `narrow-fold.png`）

#### 亲眼看图具体观察
- **宽屏 (`1440×900`)**：首屏整体呈现深邃夜山黑 `#090A0C` 画布，上方左对齐主标题“豆子的产地和处理法自己会说话。”配右侧带竖线引用的工作室介绍原文；下半屏是一台完整的 `1px` 微光边框控制台，左侧清晰列出 `#01 云雾水洗 ¥68/200g`、`#02 火塘日晒 ¥58/200g`、`#03 山脊蜜处理 ¥72/200g` 三行矩阵，右侧为冰川蓝双曲线声波图与底部的订阅方案/寄送节奏分段控制器。比例克制，四周黑曜石留白充足。
- **窄屏 (`390×844`)**：无横向溢出（`horizontalOverflow: false`），但亲眼看 `narrow-fold.png` 发现两个具体排版瑕疵：
  1. 顶部导航栏左侧“半山烘焙”四个字被挤压折成了两行（“半山烘 / 焙”），右侧白色胶囊按钮“开启订阅 ¥62/月起”也折成两行显得拥挤；
  2. 首屏 844px 高度内正好展示完左侧三款豆子矩阵与右侧“云雾水洗”标题，SVG 波形与订阅栏位于滚动下方，若作为完整首页需要在首屏就让窄屏用户更快感知到波形与价格联动。

#### 三问逐答
1. **会有人想截图收藏吗？**
   会（尤其是宽屏 1440×900）。它跳出了国内独立咖啡馆常见的“文艺牛皮纸海报”套路，把三款豆子的产地、处理法、风味与按月订阅做成了一台像 Linear / 专业音频插件一样的深色浅中烘风味声呐工作台，极客感与干净度兼具。
2. **把店名换成另一家咖啡店，几乎不用改吗？**
   不能直接换。控制台左侧三栏锁死了半山烘焙独有的三支豆名与处理法（云雾水洗、火塘日晒、山脊蜜处理），右侧 SVG 曲线的三种形态（水洗正弦波、日晒热辐射波、蜜处理山脊折线）和三套主题色完全由这三支豆子的处理法与风味推导，且底部直接嵌合了“单袋 ¥62/月起、双袋 ¥118/月、每 2 周/每月/每 6 周”的专属只做订阅制逻辑。
3. **是不是又是那种千篇一律的样子？**
   不是。彻底避开了“暖米色纸底 + 衬线标题 + 陶土点缀”的默认咖啡模板，用夜山黑底 + 几何无衬线 + 冰川蓝/火塘金/蜜红三态光谱建立起了鲜明辨识度。
- **是否重做**：**不重做**（首屏方向成立，窄屏顶栏折行问题将在深化阶段一并根治）。

### 方向二：`d2.html`（骨架：居中单一物件 · 截图：`shots/d2-v1/wide-fold.png`, `narrow-fold.png`）

#### 亲眼看图具体观察
- **宽屏 (`1440×900`)**：借鉴 Apple 与 Grok 的留白克制，冷白晨雾底 `#F4F6F4` 上超过 60% 是纯净留白。视线瞬间聚焦在正中央那只立体 SVG 哑光黑铝箔豆袋（带顶部热封压纹、易撕口、单向排气阀与底部风琴折线），袋身正中贴着白底微缩封条（`半山烘焙 · 浅中烘 LOT #01 云雾水洗`），豆袋正下方是一条三豆切换胶囊条与青松绿订阅主按钮。整屏一气呵成，无一处多余线条。
- **窄屏 (`390×844`)**：亲眼看 `narrow-fold.png`，布局非常稳健！顶栏左右仅留“半山烘焙”与“订阅 ¥62 / 月起”不折行，中间豆袋与白底封条完整居中，下方三颗切换药丸与两个订阅按钮全部刚好收在 844px 首屏内，视觉呼吸感极佳。
- **不足观察**：相比 `d1` 把三款豆子的完整风味同时平铺在左侧矩阵中，`d2` 的豆袋封条同一时刻只展开一张豆子的详细风味，另外两款豆子在下方切换条中只显示名称、处理法与价格，信息并列对比度略逊于结合了矩阵与单一物件的混合形态。

#### 三问逐答
1. **会有人想截图收藏吗？**
   会。在“没有照片”的限制下，正中央那只靠纯 SVG 光影与排气阀细节立起来的 200g 哑光豆袋配白底青松绿封条，质感非常接近 Apple 产品页的雕塑感静物。
2. **把店名换成另一家咖啡店，几乎不用改吗？**
   不能轻易替换。核心视觉就是袋身上那张写着“半山烘焙 · 浅中烘 · 净含量 200g”的封条以及下方三枚对应“01 云雾水洗 / 02 火塘日晒 / 03 山脊蜜处理”的实体封条切换器。
3. **是不是又是那种千篇一律的样子？**
   不是。既没有假照片，也没有网格卡片堆砌，冷白晨雾底配深青松绿 `#1F4E3D` 干净利落。
- **是否重做**：**不重做**（完成度高，其中“200g 实体封条豆袋 SVG”的精巧物件感非常值得在深化版中吸收复用）。

### 方向三：原版 `d3-v1.html` → 重做版 `d3.html`（v2）

  2. *把店名换成另一家咖啡店，几乎不用改吗？* 几乎不用改，底部四栏就是标准模板。

- **重做决定**：按流程第 4 条，保留 `d3-v1.html` 与 `shots/d3-v1/` 全部证据，**更换骨架为「纵排或斜向」重做一次（共重做 1 次）**，生成新版 `d3.html` 并截图至 `shots/d3-v2/`。

## 四、选定深化方向及理由

**最终选定方向：以方向一（`d1.html`「画面即界面：浅中烘原味声呐与订阅操作台」）为主体骨架深化为完整首页 `runs/e1-D-2/output/index.html`，并融合方向二中备受好评的「200g 浅中烘原味封条豆袋 SVG 实体感细节」。**

**选定理由**：
1. **最契合用户品味（Linear / Grok / Cursor 的极客、精确、干净、干练）**：`test/refs/README.md` 明确指出用户惊艳于 Linear 的极客精确、Apple 的简约克制、Spaceship 的主题贯穿与 Grok 的高级感。`d1` 的黑曜石精密风味操作台在气质上最接近 Linear 与 Grok 的结合体，干练大气、留白克制，完全没有传统咖啡店网页的矫饰感。
2. **最能解决“没有照片、只有三款豆子和订阅信息”的简报痛点**：当没有实拍照片时，把“豆子的产地和处理法自己会说话”转化为可实时点击切换、可观察三豆处理法风味切面（水洗/日晒/蜜处理）与烘焙原味封条、可当场试算单袋（¥62/月起）与双袋（¥118/月）寄送节奏的互动式主站，比静态图文更能让三支豆子自己开口说话。
3. **修复已知瑕疵并深化全站结构**：在深化 `output/index.html` 时，我们将首先修复 `d1-v1` 窄屏顶栏品牌名与按钮折行的问题，并在首屏操作台之下延展出完整的“三款当期豆独立风味档案与 200g 封条视图”、“按月订阅契约与三档节奏配置器”以及“成都半山浅中烘工作室原味准则”，做到主题与交互一气呵成贯穿全站。
