# 半山烘焙 · 三个首屏方向卡（E1-D-1）

## 全局一句话北极星
> **第一眼让人感受到成都半山腰的清冽留白与克制锋芒——没有一张修饰性照片，仅凭“云雾水洗、火塘日晒、山脊蜜处理”三支豆子的产地风味光谱与浅中烘的精确尺度，就让人立刻想按月订一袋回家。**

---

## 方向一（`directions/d1.html`）：浅中烘风味光谱与按月订阅调阅台

- **北极星**：让首屏本身成为一台极客、克制、零废话的“浅中烘风味光谱调阅台”，第一眼用精确的风味曲线与实时豆袋封签建立专业烘焙工作室的信任感。
- **骨架**：**画面即界面**（首屏 1440×900 视口即一套完整的三栏式风味调阅与订阅交互工作台：左栏三款豆单切换、中栏动态 SVG 风味光谱、右栏订阅周期与实时豆袋封签预览）。
- **主视觉是什么**：中栏实时绘制的「三款豆子浅中烘风味光谱与酸甜平衡曲线（SVG）」及右栏联动生成的「当期 200g 豆袋封签预览单」。
- **字体**：现代几何无衬线 `Plus Jakarta Sans` + `Noto Sans SC`（标题紧字距 `-0.025em`，干练利落）搭配等宽技术字体 `JetBrains Mono`（用于展示价格 `¥68 / 200g`、豆单编号、光谱坐标与寄送周期）。
- **色彩及其来源**：
  - **主底色**：成都夜雨半山雾黑 `#090A0D` 与曜石面板 `#101218`（致敬 Linear 的精密深色界面美学）。
  - **文字色**：山雾冷白 `#ECEFF4` 与岩灰 `#9AA3B2`。
  - **三豆动态风味点缀色**：取自三支豆子的核心风味——云雾水洗的「茉莉青柠绿 `#7EE2B8`」、火塘日晒的「烤坚果暖珀 `#E8985A`」、山脊蜜处理的「红苹果蜜红 `#F26D5B`」。彻底避开“暖米色纸底 + 衬线标题 + 陶土点缀”的默认咖啡模板外观。
- **唯一最大胆的一处**：彻底取消传统营销头图与装饰性横幅，把整个 1440×900 首屏做成一台可直接切换三款豆子、三种寄送节奏（每 2 周 / 每月 / 每 6 周）并实时重绘风味曲线与出炉封签的精密调阅仪器。
- **这个设计里哪样东西是这家店才有的**：「云雾水洗 / 火塘日晒 / 山脊蜜处理」三支成都半山豆在“偏浅中烘·酸甜平衡段”上的三段式风味坐标点（前段干湿香、中段风味主轴、尾韵延展）与“每期 1 袋 200g 按月寄送”的实时出炉封签联动。

## 方向二（`directions/d2.html`）：云雾留白中的 200g 订阅豆袋雕塑

- **北极星**：在如成都高山晨雾般超过 68% 的纯净冷白留白中，只放一袋触手可及的 200g 哑光铝箔单向排气阀豆袋，让“每期 1 袋 200g 按月寄送到家”的实体交付感扑面而来。
- **骨架**：**居中单一物件**（致敬 Apple 与 Grok 的极致留白与克制聚焦，全屏视觉重心完全收束于中央悬浮的单体 200g 豆袋构造与底部胶囊订阅栏）。
- **主视觉是什么**：悬浮于冷白留白中央的「半山烘焙 200g 哑光铝箔订阅豆袋与单向排气阀 SVG 精密立体构造物」，袋身正面贴有可切换三款豆子的批次封签，两侧辅以极细建筑引线标注。
- **字体**：现代建筑感窄体展示无衬线 `Syne`（700/600）+ 人文无衬线 `Instrument Sans` + `Noto Sans SC`（300/500），字形干净修长、呼吸感强。
- **色彩及其来源**：
  - **主底色**：半山高海拔晨雾冷白 `#F4F7F5`（纯净通透，避开暖黄米色纸底）。
  - **主文字色**：深冷杉墨绿黑 `#0F1A15` 与冷灰绿 `#4A5D54`。
  - **点缀色**：取自「云雾水洗（埃塞俄比亚 耶加雪菲）」茉莉花茶与柠檬叶的「高山茶青色 `#1B6B50`」。
- **唯一最大胆的一处**：全屏不放任何背景框、不放多列卡片墙，留出近 70% 的冷白负空间，仅靠中央一袋 200g 豆袋上的单向排气阀、热封易撕口和浅中烘批次封签撑起整屏张力。
- **这个设计里哪样东西是这家店才有的**：专为半山烘焙“每期 1 袋 200g、标注烘焙日期与风味描述”定制的袋身正面批次封签构造图，以及「云雾水洗 / 火塘日晒 / 山脊蜜处理」三款豆子封签色带的原位切换。

## 方向三（`directions/d3.html`）：初版 v1（左右分栏）→ 重做版 v2（满版裁切文字与三豆切面签）

> **重做说明**：初版 `d3-v1.html` 采用「左右分栏」骨架与暖米色纸底+衬线+赤陶点缀，看图自评发现其版式过于接近常规精品咖啡馆模板（详见 `critique.md`）。因此按规则更换骨架重做一次为 `d3-v2.html`（并更新至 `d3.html`），保留 `d3-v1.html` 与 `shots/d3-v1/` 原版证据。

### 方向三最终版（`d3-v2` / `d3.html`）方向卡
- **北极星**：把“半山”二字化作横跨整屏並向视口四周出血裁切的山脊等高线碑刻，在深邃的成都暮色山岚中让三支豆子的山地命名（云雾、火塘、山脊）拥有具体的文化与地理重量。
- **骨架**：**满版文字（字大到占满首屏或被裁切）**（520px–540px 的超巨幅汉字「半」「山」与斜体衬线词「TERROIR / WASHED / NATURAL / HONEY」占满 1440×900 画布并向边缘裁切出血，前景叠印三枚竖向豆单标本签）。
- **主视觉是什么**：向画布四周裁切出血、字形内部嵌有「云雾·火塘·山脊」三道铜金等高线纹理的超巨幅「半山」字形地貌（SVG），与前景三枚「云 / 火 / 山」半透明毛玻璃风味标本签形成强烈的尺度对比。
- **字体**：超粗高对比中英衬线组合 `Noto Serif SC`（900 Black 超大字号出血展示）+ `Cormorant Garamond`（700 Italic 古典斜体编号与英文处理法水印）。
- **色彩及其来源**：
  - **主底色**：成都傍晚半山腰云雾初合时的「暮色深靛蓝 `#0A0F1D` 至 `#0D1426`」（吸取 Dishoom 的深色文化氛围与 Spaceship 的深邃蓝调光感）。
  - **文字色**：宣纸雾白 `#F3EFE6` 与山岚灰蓝 `#A9B4C9`。
  - **点缀色**：取自「火塘日晒」与山间夜火的「火塘暖铜金 `#D98A4E`」。
- **唯一最大胆的一处**：将 540px 字号的「半山」二字直接放大到撑破 1440×900 视口边界并做边缘裁切，把汉字笔画本身变成承载成都半山等高线纹理解剖图的主视觉容器。
- **这个设计里哪样东西是这家店才有的**：将品牌名「半山」与三款豆子名字里的山野意象——「云（云雾水洗）」「火（火塘日晒）」「山（山脊蜜处理）」直接铸入巨幅出血字形与三联竖签水印之中，离开“半山烘焙”这四个字和这三支豆名便无法成立。
