桌面客户端菜单、快捷键与右键菜单设计规范 (Windows / macOS 双端适配)
适用于 Electron 或 Tauri 桌面外壳 · 支持在顶部直接下拉体验主菜单，或在工作台各区域点击鼠标右键唤出上下文菜单
一、顶部应用菜单栏设计（Application Menu）
Windows 下渲染为窗口顶部内嵌自定义菜单栏（支持 Alt+字母助记键）；macOS 下通过 Electron Menu.setApplicationMenu / Tauri Menu 映射至系统顶栏。
1. 文件 (File)Alt+F
  • 新建项目…Ctrl+N / ⌘N
  • 打开本地项目目录…Ctrl+O / ⌘O
  • 导入提示词与参数…Ctrl+I / ⌘I
  • 导出选中占位结果…Ctrl+E / ⌘E
  • 设置 / 首选项…Ctrl+, / ⌘,
  • 退出客户端Alt+F4 / ⌘Q
2. 编辑 (Edit)Alt+E
  • 复制正向提示词Ctrl+C / ⌘C
  • 复制负面提示词Ctrl+Shift+N / ⇧⌘N
  • 复制完整生成参数Ctrl+Shift+C / ⇧⌘C
  • 粘贴参数至检查器Ctrl+V / ⌘V
  • 全选当前项目网格Ctrl+A / ⌘A
  • 移出选中结果项Del / ⌫
3. 视图 (View)Alt+V
  • 四栏工作台视图Ctrl+1 / ⌘1
  • 菜单与快捷键规范Ctrl+2 / ⌘2
  • 显示/折叠底部队列Ctrl+J / ⌘J
  • 显示/折叠参数检查器Ctrl+B / ⌘B
  • 网格缩放增大/减小Ctrl+± / ⌘±
4. 任务与队列 (Task)Alt+T
  • 按当前参数加入队列Ctrl+Enter / ⌘↵
  • 重试失败任务 (task-b1)Ctrl+R / ⌘R
  • 暂停 / 恢复本地队列Ctrl+P / ⌘P
  • 清理已完成任务记录Ctrl+Shift+K / ⇧⌘K
  • 中止当前采样任务Esc
5. 帮助 (Help)Alt+H
  • 快捷键与右键菜单速查Ctrl+/ / ⌘/
  • 显存不足排障指引F1
二、全局与面板级快捷键设计（Windows / macOS 对照）
围绕「选项目 → 浏览结果网格 → 检查/复用参数 → 操控队列重试」高频闭环设计，避免与系统输入法冲突。
作用域 功能动作 Windows 快捷键 macOS 快捷键 交互反馈与说明
全局 / 检查器 使用当前检查器参数提交生图队列 Ctrl + Enter ⌘ + Return 立即将当前选中的 Prompt / Seed / 尺寸追加到底部任务队列
中间结果网格 上下左右切换选中占位图片 ↑ ↓ ← → ↑ ↓ ← → 右侧参数检查器实时同步更新对应卡片的提示词、负面词、Seed 与尺寸
中间结果网格 快速预览 / 对比当前选中占位图 Space Space 保持焦点在网格内，高亮显示尺寸比例与采样步数
参数检查器 一键复制完整生成参数 Ctrl + Shift + C ⇧ + ⌘ + C 复制包含提示词、负面提示词、种子、steps 与尺寸的结构化文本
底部任务队列 重试失败的任务（如显存不足的 task-b1） Ctrl + R ⌘ + R 将 task-b1 状态重置为排队中/生成中并重新执行采样
布局面板控制 显示 / 隐藏底部任务队列面板 Ctrl + J ⌘ + J 当需要更大面积浏览中间结果网格时一键收起底部队列
布局面板控制 显示 / 隐藏右侧参数检查器 Ctrl + B ⌘ + B 切换右侧 320px 参数检查器的展开状态
三、三类上下文右键菜单设计（Context Menu · 可在工作台直接右键实测）
针对「左侧项目列表」「中间结果网格卡片」「底部队列任务行」三类不同对象提供专属右键菜单，支持键盘快捷键提示与禁用态区分。
A. 中间结果网格卡片右键菜单 触发：右键任意「占位」卡片
  • 在右侧检查器中查看参数Enter
  • 复制提示词（prompt）Ctrl+C / ⌘C
  • 复制负面提示词Ctrl+Shift+N
  • 复制种子（Seed）Alt+S / ⌥S
  • 复制全部参数 (Prompt+Seed+尺寸)Ctrl+Shift+C
  • 锁定此 Seed 重新入队生成Ctrl+Enter
  • 固定提示词并随机新 Seed 入队Ctrl+Shift+Enter
  • 在本地文件夹中显示 (Explorer/Finder)Ctrl+Shift+R
  • 从当前项目中移除占位项Del / ⌫
B. 底部任务队列行右键菜单 触发：右键任意 task-* 行
  • 加载任务参数到右侧检查器Enter
  • 重试失败任务（针对显存不足 task-b1）Ctrl+R / ⌘R
  • 调整队列优先级：置顶排队（针对 task-a2）Alt+↑
  • 中止正在采样的任务（针对 task-a1）Esc
  • 复制任务 ID 与种子 (Seed)Ctrl+C / ⌘C
  • 从队列列表中移除已完成项（task-c1）Del / ⌫
C. 左侧项目列表项右键菜单 触发：右键任意项目名称
  • 切换到此项目Enter
  • 以此项目新建生图任务Ctrl+Enter
  • 重命名项目…F2
  • 在文件管理器中打开项目目录Ctrl+Shift+O
  • 导出项目参数清单 (JSON)Ctrl+E
  • 删除空项目（仅限 0 张图片项目）Del / ⌫
